What it does

[ FEATURES ]
01

The key stays home

Each application holds one .TM file containing an ECDSA P-256 private key, encrypted at rest with a password only you know.

02

Signed, single-use requests

To read a secret, the library unlocks the key in your own process, signs a 60-second assertion and sends only the signature.

03

A breach can't forge anything

The server stores just the public half of the key, so a full database breach cannot forge a request for any application.

04

One line to read a secret

TrustMe.get("STRIPE_API_KEY"). The same call exists in the Java, Python and JavaScript libraries.

05

Made for pipelines

Supply the password on stdin or from a file. There is a Jenkins recipe, and no environment variables to leak.

06

Share with your team

Invite people by Google account email. Members can read and change secrets; only the owner can delete the app or manage access.

How a secret is read

[ HOW IT WORKS ]
UNLOCK

Open the key

The library finds the .TM file and unlocks it with your password (Argon2id, then AES-256-GCM).

SIGN

Prove who you are

It signs a short-lived, single-use assertion with the private key, inside your own process.

VERIFY

Get the secret

The cloud function checks the signature, rejects replays and expired assertions, then returns the value.

JAVA
// the key file and password are asked for once, at start-up
String key = TrustMe.get("STRIPE_API_KEY");
