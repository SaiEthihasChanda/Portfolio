What it does

[ FEATURES ]
01

A CLI and a background daemon

The tether command manages files; tetherd keeps them in sync in the background and starts at login.

02

Delta sync

Files are split into content-defined chunks and only the missing chunks travel, so a one-line edit stays tiny.

03

Share with an ID

Manage a file, get a share ID, and run tether pull on another machine or account.

04

Live editing sessions

With tether edit --realtime, every save is pushed live to everyone until you run tether done.

05

Git-aware

Inside a git repo you choose keep, skip or follow, so Tether never gets in the way of git status or pulls.

06

Web console and roles

Create repos, invite editors by email and review everything in the console. Desktop notifications cover conflicts and revoked access.

Try it in four commands

[ HOW IT WORKS ]
LOGIN

Sign in

tether login opens a browser sign-in. The hosted service is the default.

MANAGE

Put a file under Tether

tether manage prints a share ID for the file you chose.

PULL

Get it anywhere

tether pull with that ID creates an identical copy on any other machine.

TERMINAL
$ tether login
$ tether repo create team
$ tether manage .editorconfig --repo team   # prints a share ID
$ tether pull abcd-efgh-jkmn                   # on another machine
