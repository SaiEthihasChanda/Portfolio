Tether

Keeps a shared file identical wherever it is pulled. A copy follows the file through moves and renames, undoes local edits until you ask to change it, and sends only the parts that changed. Use the Windows app, or the command line.

What it does

[ FEATURES ]
01

An app for everyone, a CLI for developers

The Windows app has a tray icon, a window and a right-click menu in File Explorer, so nobody needs a terminal. The tether command does the same from the command line. Both use tetherd, the background service that keeps files in sync.

02

Follows the file

Move or rename a managed file and Tether still knows it. If a drive disappears, tether locate re-links the copy by content.

03

Delta sync

Files are split into content-defined chunks and only the missing chunks travel, so a one-line edit stays tiny.

04

Edit on purpose, live if you like

Local edits are undone until you run tether edit. Editors can go live with --realtime: every save reaches everyone within seconds.

05

Access and history

Share by ID with editors, viewers or an allowlist, rotate the ID, and roll back to any version. Nothing is ever overwritten.

06

Git-aware

Inside a git repo choose keep, follow or skip, so Tether never gets in the way of git status or pulls.

Try it in a few commands

[ HOW IT WORKS ]
INSTALL

Install and sign in

Run the Windows installer and sign in with your browser. Windows may say it protected your PC because the installer is not code-signed yet: choose More info, then Run anyway. Prefer a terminal? npm i -g tether-sync, then tether login (Node 22.13 or newer).

MANAGE

Put a file under Tether

Drag it onto the app, right-click it in File Explorer, or run tether manage. You get a share code.

PULL

Get it anywhere

Open a share code in the app, or run tether pull with it, to create an identical, managed copy on any other machine.

TERMINAL
$ npm i -g tether-sync
$ tether login
$ tether repo create team
$ tether manage .editorconfig --repo team   # prints a share ID
$ tether pull abcd-efgh-jkmn                   # on another machine
